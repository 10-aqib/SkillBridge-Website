# SkillBridge

SkillBridge is a local skills marketplace that connects customers who need work done with verified skilled workers.

## Features
- Complete Authentication (Customer, Worker, Admin)
- Job Posting & Matching
- Worker Discovery & Profiles
- Proposal System
- Real-time Chat
- Reviews and Ratings
- Admin Dashboard
- Responsive Design

## Technology Stack
- **Frontend**: React.js, Vite, Tailwind CSS, Framer Motion, Socket.IO Client, Three.js
- **Backend**: Node.js, Express.js, MongoDB, Mongoose, Socket.IO, JWT

## Project Structure
- `/frontend` - React application
- `/backend` - Node.js Express API server

## Environment Variables
Create `.env` files in both `frontend` and `backend` directories based on the `.env.example` files provided.

## Running the Application
### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
